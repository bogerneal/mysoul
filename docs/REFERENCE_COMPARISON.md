# 與參考氣象地圖的功能比較

檢查日期：2026-10-05（Asia/Taipei）。來源：https://taiwan-weather-map.vercel.app/
本次以 Edge 實際開啟網站、檢查畫面並切換雨量、雷達、颱風及風速風向。
這是介面功能盤點，未稽核對方資料正確性、後端架構或更新排程。

## 核心差異

參考網站主打即時測站觀測；mysoul 主打一週縣市預報。
現有 22 縣市代表點與每日最低／最高溫，不能當作即時測站讀值。

| 面向 | 參考網站可見功能 | mysoul 目前狀態／差距 |
| --- | --- | --- |
| 資料 | 即時觀測、測站數、觀測時間及資料快取狀態 | 已有 CWA 一週預報；需新增獨立觀測資料管線 |
| 氣象欄位 | 氣溫、雨量、風速風向、濕度、天氣 | 目前只有預報最低／最高溫 |
| 地圖呈現 | 全畫面地圖、浮動控制區、連續色彩覆蓋、數字標籤 | 目前為 Streamlit 儀表板內代表點地圖，缺縣市界線與覆蓋圖層 |
| 雷達 | 雷達圖層入口與控制 | 未串接；需要確認影像來源、時間及可用範圍 |
| 颱風 | 過去／預報路徑、不確定範圍、暴風圈與時間控制 | 未串接 |
| 天氣特報 | 警報類型、內容、有效時間及來源 | 未串接；需要去重、失效處理與區域對應 |
| 地圖操作 | 測站圖層、縣市界線、標籤開關、深色／街道底圖、定位 | 已有點選縣市、縮放與底圖開關；其餘未完成 |
| 統計 | 觀測最高／最低溫、最大雨量／風速及站名 | 目前為所選縣市每日預報摘要與趨勢 |
| 分享 | 可直接用公開網址瀏覽 | 目前僅本機服務，GitHub 儲存程式不等於網站已部署 |

## 建議順序（規畫，尚未實作）

1. 保留既有一週預報，增加「即時觀測／一週預報」明確切換，先接即時氣溫與測站。
2. 加入雨量、風速風向、濕度，再補縣市界線與測站明細。
3. 加入天氣特報與定位，改善地圖版面及手機操作。
4. 完成公開部署、伺服器端金鑰設定與快取更新政策。
5. 加入雷達、颱風路徑及時間控制；連續色彩圖層需先釐清來源與估算方法。

公開部署可依展示需求提前。若目標是高度接近參考網站的全螢幕多圖層互動，
先評估 Streamlit 能否滿足操作需求，再決定是否另外建立 Leaflet／MapLibre 前端。
新增資料源的 CWA 授權／配額需逐項確認；瀏覽器定位需要使用者同意。

本次只有比較文件更新，沒有新增上述功能；本文件與進度紀錄一併納入 GitHub 版本管理。
